ساخت APK فقط با موبایل (بدون کامپیوتر)

این پروژه شامل فایل گردش‌کار GitHub Actions است تا ساخت APK روی سرور GitHub انجام شود.

۱) در مرورگر گوشی وارد https://github.com شوید و حساب رایگان بسازید/وارد شوید.
۲) یک مخزن جدید (New repository) بسازید؛ نام دلخواه، ترجیحاً mamad-ga-wallet-finder، و آن را Public انتخاب کنید.
۳) فایل‌های داخل پوشه mamad_ga_wallet_finder را در مخزن بارگذاری کنید (محتویات پوشه، نه خود پوشه‌ی بیرونی ZIP). فایل مخفی .github/workflows/build-apk.yml نیز باید بارگذاری شود.
۴) پس از بارگذاری، زبانه Actions را باز کنید و گردش‌کار Build Android APK را انتخاب کنید؛ اگر اجرا نشد، Run workflow را بزنید.
۵) پس از پایان موفق، وارد اجرای سبزرنگ شوید، بخش Artifacts را باز کنید و MAMAD-GA-WALLET-FINDER-APK را دانلود کنید.
۶) ZIP آرتیفکت را باز کنید و app-debug.apk را نصب کنید. ممکن است اندروید اجازه نصب از منبع مرورگر/فایل‌منیجر را بخواهد.

نکته: GitHub Actions ساخت را روی سرور انجام می‌دهد؛ نیازی به نصب Android Studio روی گوشی نیست. فایل APK خروجی، نسخه debug است و برای انتشار عمومی امضای release جداگانه لازم دارد. کلیدهای خصوصی واقعی را در مخزن یا GitHub قرار ندهید.
